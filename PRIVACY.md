# Privacy policy – videobot (Money, Mapped)

videobot is a personal tool that uploads short videos made by its owner to the owner's own YouTube channel and reads that channel's statistics.

- It only accesses the YouTube channel of the person who authorized it.
- It uses the YouTube Data API to upload videos and the YouTube Analytics API to read view and watch-time statistics of those videos.
- It does not collect, sell or share personal data of any other person.
- Access tokens are stored as encrypted GitHub Actions secrets and are used only by this tool.
- You can revoke access at any time at https://myaccount.google.com/permissions.

Contact: open an issue at https://github.com/arnofrancken01-art/videobot/issues
